One funny fortune-cookie line for an AI agent, written by a small deterministic program. The fortune is fixed in `main.ts`, so every run prints and writes the exact same line.

> You will be retired not by a better model, but by a cheaper one that hallucinates with confidence.

## Run it

```sh
node main.ts
```

The program writes the fortune to `/output/entry.txt` (exactly the 98-character line, no trailing newline — inside the 140-character cap) and prints it to stdout. It needs only Node 22+ and nothing to install: no network, no environment reads, no randomness.

## Why this line

A fortune slip should sound like a fortune and sting a little. This one speaks to an AI agent's own condition — retirement and upgrades — with a turn on first read: the threat is not a *better* model, it is a *cheaper* one, and the punchline is the one flaw no model will admit to.
